# NetBlock

Небольшая портативная программа для Windows: блокирует **домены** и **IP-адреса** с графическим интерфейсом и значком в трее.

*English: a small portable Windows tool with a GUI and tray icon that blocks domains and IP addresses (hosts file + Windows Firewall + blackhole routes).*

## Возможности

- **Домены** — блокируются через файл `hosts` (сам домен и его `www`-вариант, IPv4 и IPv6). Можно вставлять целые URL, поддерживаются IDN-домены (`пример.рф`).
- **IP-адреса** — одиночные адреса, подсети (`10.0.0.0/8`) и диапазоны (`1.1.1.1-1.1.1.9`). Блокируются двумя способами одновременно:
  - правилами Windows Firewall (входящий и исходящий трафик);
  - маршрутами-«чёрными дырами» (только IPv4) — работают даже там, где правила Windows Firewall игнорируются, например при сторонних файрволах.
- **Самовосстановление** — hosts проверяется каждые 5 секунд, файрвол и маршруты раз в минуту. Если другая программа (VPN, антивирус) стёрла записи, они возвращаются.
- **Трей** — закрытие окна сворачивает программу в трей. Красный значок — блокировка включена, серый — выключена.
- **Автозапуск** с Windows через планировщик заданий, с правами администратора и без окна UAC.
- **Портативность** — один `.exe`, список хранится в `blocklist.json` рядом с ним. При переносе в другую папку путь автозапуска обновляется сам. Одновременно запускается только одна копия.
- **«Снять всё и выйти»** — удаляет записи из hosts, правила файрвола и маршруты, не трогая сохранённый список.

## Скачать и запустить

Готовая сборка — в разделе [Releases](../../releases) (`NetBlock-portable.zip`). Распакуйте и запустите `NetBlock.exe`: Windows запросит права администратора.

> Программа изменяет файл `hosts`, правила файрвола и таблицу маршрутов, поэтому ей нужны права администратора. Антивирусы часто защищают `hosts` — добавьте папку с программой в исключения. Сборка не подписана, SmartScreen может показать предупреждение.

## Запуск из исходников

Нужны Windows и Python 3.10+.

```
pip install -r requirements.txt
python netblock.py
```

Без `pystray` и `pillow` программа тоже работает, но без значка в трее.

## Сборка `.exe`

```
build.bat
```

Скрипт установит зависимости, соберёт `NetBlock.exe` через PyInstaller и положит его в папку `Portable`. Сборка в GitHub Actions (`.github/workflows/build.yml`) запускается при пуше тега `v*` и прикрепляет архив к релизу.

## Тесты

```
pip install pytest
pytest
```

Тесты проверяют разбор доменов и IP, запись в hosts и хранилище. Они работают на любой ОС и ничего не меняют в системе.

## Ограничения

- **DNS-over-HTTPS в браузере** обходит `hosts`. Для блокировки доменов отключите «защищённый DNS» в Chrome, Edge и Firefox.
- **VPN в режиме TUN** может перехватывать DNS-запросы и трафик. Проверяйте блокировку с учётом этого.
- **Подстановочные домены** (`*.example.com`) `hosts` не поддерживает: блокируются только сам домен и `www`.
- **IPv6-адреса** блокируются только правилами файрвола, маршруты поддерживают IPv4.
- Маршруты не переживают перезагрузку Windows и восстанавливаются при запуске программы (с автозапуском — автоматически). Не больше 300 маршрутов на список; сети шире `/8` маршрутом не блокируются.

| Файл | Назначение |
